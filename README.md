# ForeverRealsReminder

After you kill a dungeon boss at level 60, shows the **Tarnished Undermine Real** icon at the top of the screen
so you don't forget to loot it. It disappears when you loot the Real, or after 30 seconds.

- Only in the dungeons that drop Reals: Blackrock Depths, Lower/Upper Blackrock Spire, Dire Maul,
  Scholomance, Stratholme, Blackmaw Hold and Shaper's Terrace. If a Real drops somewhere else, that dungeon
  is learned and added.
- Skips bosses below level 55 (they don't drop Reals), bosses you already looted a Real from today, and
  when you're at the 250 cap.

## Commands
- `/frr`: options (on/off, size, how long it stays up)
- `/frr test`: show a test reminder
- `/frr unlock` / `/frr lock`: move it
